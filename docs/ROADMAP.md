# نقشه راه الکی‌پلکی

این مخزن فعلاً مرحله پایه را دارد. قابلیت‌های پیام‌رسان را تا زمان پیاده‌سازی و آزمایش مربوطه آماده یا امن فرض نکنید.

## مراحل اجرایی
1. اتصال Cloudflare Workers و ساخت D1؛ ثبت شناسه پایگاه داده در تنظیمات.
2. احراز هویت امن، نشست‌های هش‌شده، انقضا و خروج از همه دستگاه‌ها.
3. مجوزدهی سمت سرور بر اساس عضویت چت و نقش.
4. پیام‌های متنی با پاسخ، ویرایش، حذف، فوروارد، واکنش و دیدگاه.
5. گروه‌ها و کانال‌ها، نقش مدیر و تنظیمات حریم خصوصی.
6. R2 برای عکس، صوت و فایل؛ محدودیت اندازه و نوع فایل.
7. پیام‌رسانی زنده با Durable Objects.
8. ربات‌ها با توکن‌های قابل ابطال، محدودیت نرخ و مجوزهای مشخص.
9. پنل مدیریت، گزارش تخلف و ابزارهای ضد هرزنامه.
10. آزمایش خودکار، دسترس‌پذیری صفحه‌خوان، امنیت و پشتیبان‌گیری.

## منابع Cloudflare
- Workers Builds: https://developers.cloudflare.com/workers/ci-cd/builds/
- D1: https://developers.cloudflare.com/d1/
- R2: https://developers.cloudflare.com/r2/
- Durable Objects: https://developers.cloudflare.com/durable-objects/

فایل wrangler.toml عمداً شناسه جایگزین D1 دارد. قبل از انتشار باید D1 ساخته و شناسه واقعی آن ثبت شود. هرگز توکن API یا رمز عبور را در Git قرار ندهید؛ برای CI از Secrets استفاده کنید.
